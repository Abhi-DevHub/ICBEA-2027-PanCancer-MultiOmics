# Results

Generated by the pipeline in `src/` (and the notebook). Each CSV is the exact
output consumed by the paper's tables.

| File | Produced by | Contents |
|---|---|---|
| `5fold_cv_results.csv` | `run_xgboost.py` | 5-fold CV weighted precision / F1 / accuracy (4 models) |
| `per_class_report.csv` | `run_xgboost.py` | per-class precision / recall / F1 / support |
| `kappa_macro_results.csv` | `metrics_kappa.py` | Cohen's κ and macro-F1, holdout + CV, 4 models |
| `repeated_cv_paired.csv` | `repeated_cv_wilcoxon.py` | 25 paired fold scores (XGBoost vs Logistic Regression) |
| `wilcoxon_results.csv` | `repeated_cv_wilcoxon.py` | Wilcoxon n / W / p / mean Δ per metric |
| `ablation_comparison.csv` | `ablation_mrna.py` | full multi-omics vs mRNA-only |
| `class_mapping_0_31.csv` | `make_class_mapping.py` | class → TCGA code → cancer name → n samples |
| `feature_importance.csv` | `interpret_xgboost.py` | split-gain importance per feature |
| `shap_top20.csv` | `interpret_xgboost.py` | mean absolute SHAP per feature |
| `roc_auc.csv` | `interpret_xgboost.py` | per-class and macro one-vs-rest ROC-AUC |
| `pr_curve.csv` | `interpret_xgboost.py` | per-class and macro average precision |

ORA outputs (`ora_from_shap.py`, written to `ORA_results/`):

| File | Contents |
|---|---|
| `ranked_mrna_shap.csv` | mRNA features ranked by mean \|SHAP\| |
| `top_{N}_genes.txt` | top-N gene lists (N = 100, 150, 200) |
| `ora_top{N}_raw.csv` | raw hypergeometric p-values per cell type |
| `ora_top{N}_adj.csv` | Benjamini–Hochberg adjusted p-values |
| `ora_top{N}_significant.csv` | sets with adj. p ≤ 0.05 |
| `ora_top{N}_dotplot.png` | ORA dot plot (top 20 cell types) |
| `ORA_metadata.json` | parameters used for the run |

> `ORA_results/` is generated at run time and is not pre-populated, because the
> CellMarker library must be obtained separately.
