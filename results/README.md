# Results

All files here are generated by the pipeline in `src/`. **`metrics/` and
`statistical_analysis/` are the authoritative results**; `superseded/` holds the
earlier full-cohort-CV outputs and must not be quoted in the paper.

## metrics/

| File | Produced by | Contents |
|---|---|---|
| `cv_4models.csv` | notebook §6 / `revision_experiments.py` | 5-fold CV within the training partition: accuracy, weighted F1, weighted precision, macro-F1, Cohen's κ (mean ± std) for all four models |
| `per_class.csv` | notebook §6 / `revision_experiments.py` | per-class precision / recall / F1 / support for the 32 classes |
| `feature_importance.csv` | `interpret_xgboost.py` | split-gain importance per feature |
| `shap_top20.csv` | `interpret_xgboost.py` | mean absolute SHAP per feature |
| `roc_auc.csv` | `interpret_xgboost.py` | per-class and macro one-vs-rest ROC-AUC |
| `pr_curve.csv` | `interpret_xgboost.py` | per-class and macro average precision |
| `class_mapping_0_31.csv` | `make_class_mapping.py` | class id → TCGA project → cancer name → n samples |

## statistical_analysis/

| File | Produced by | Contents |
|---|---|---|
| `paired_folds.csv` | `revision_experiments.py` | 25 paired fold scores for XGBoost, SVM and Logistic Regression |
| `significance_corrected.csv` | notebook §10 / `revision_experiments.py` | mean Δ, Nadeau–Bengio corrected 95% CI, Cohen's d, corrected two-sided p, plus the uncorrected Wilcoxon p for reference |
| `ablation_point_estimates.csv` | `revision_experiments.py` | leave-one-modality-out: holdout + CV accuracy and macro-F1 for six configurations |
| `ablation_paired_uncertainty.csv` | `revision_ablation_uncertainty.py` | paired Δ versus full model over 25 folds, corrected CI and p |
| `ablation_per_fold.csv` | `revision_ablation_uncertainty.py` | raw per-fold scores for the ablation (auditable) |

Reading note: `p_wilcoxon_uncorrected` assumes independent folds and is
anti-conservative under repeated CV. Report `p_nb_two_sided` only. The
`ci_consistent_with_p` column confirms each interval agrees with its p-value.
